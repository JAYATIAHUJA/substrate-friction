# The abstention loop, demonstrated over MCP

Generated by `scripts/abstention_demo.py` — a real MCP client session against `friction-mcp` over stdio, the same protocol coding agents (Claude Code, Cursor, OpenHands) speak.

**Disclosure first:** the client's decision rule is a scripted policy, not an LLM. What is real: the MCP transport, the server, the measured verdict, and the behavioural branch. The demonstrated claim is exactly this and no more: *an external, measured signal can drive an agent-protocol abstention decision* — the piece the 2026 abstention literature (AgentAbstain: best of 17 frontier models at 59.5% paired accuracy; capability does not scale it away) identifies as missing from model-internal confidence.
