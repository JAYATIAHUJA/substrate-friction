Pre-registered in `docs/studies.md` S5 before any era was measured; generated by `scripts/longitudinal.py`; raw artifact `data/shipped/longitudinal.json`. Same extractors, same identity join as `docs/graph-delta.md`, applied to django at five release eras spanning 2017–2023.

Drift 1.11 → 5.0: **+0.0045** (0.7530 → 0.7575).

## Reading it against the registered hypothesis

S5 hypothesized the ceiling **declines** as the codebase grows. **The hypothesis is wrong — the third registered hypothesis this project has falsified against its own expectation.** The ceiling is flat: every era sits in a ~0.75 band while arm A grows from 17,782 to 24,885 edges. Name-match imprecision is not accumulating decay; it is a **stable property of the technique at any scale** — which makes the headline 0.746 a durable constant of the substrate rather than a snapshot, and means waiting for the problem to worsen (or shrink) is not a strategy. Every ceiling here is a ceiling in the same sense as the headline 0.746: pyright under-reports and never invents, so true precision per era is >= the value shown.

Reproduce: `uv run python scripts/longitudinal.py --out docs/longitudinal.md` (uses git worktrees of the existing clone; ~1–2 min per era).
