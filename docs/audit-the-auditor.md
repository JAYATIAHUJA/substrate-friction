# Audit the auditor: arm B against dynamic execution (study S2)

Pre-registered in `docs/studies.md` S2 before computation. Generated by `scripts/audit_auditor.py` from the per-instance table committed in `docs/covers.md` (the pinned output of the tracing run).

Arm B is the reference every precision figure in this project is measured against. This asks the obvious next question: what does arm B itself miss, judged against edges that provably executed?

## The 2x2, n=18 traced django instances

| | dynamic-augmented: connected | dynamic-augmented: not |
|---|---|---|
| **arm B static: connected** | 11 | 0 |
| **arm B static: not** | 1 | 6 |

- Instances the dynamic-augmented reference connects: **12**. Arm B alone finds 11 of those — it misses **1/12** (8%) despite the connection being proven by execution (`django__django-11265`).
- No instance flips the other way, as construction requires: folding executed edges in can only add connectivity.

## Result vs the registered hypothesis

The hypothesis said arm B would miss a *nontrivial fraction*. The proven miss rate on this subset is **1/12** — smaller than hypothesized, and that is the honest reading of this table. It is also only a **floor**, for the reason below.

## Why this is a floor, not the number

The dynamic reference is itself partial: only the traced edges whose endpoints joined the graph identity space count, and the per-instance mapping rate runs **15%-67%** (median 37%). An executed edge that failed to map cannot rescue an instance, so some of the 6 not/not instances may be dynamically connected in reality. Arm B's true miss rate against full dynamic truth is therefore **at least** the figure above. n=18 is small; no significance claim is made.

## What this buys the gate

Every precision number in this project calls itself a *ceiling* because arm B under-reports rather than inventing edges. This table is the direct evidence: an execution-proven connection that pyright declined to resolve. The watchmen are watched, and found incomplete in exactly the direction the ceiling framing assumed.
